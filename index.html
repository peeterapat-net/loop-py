สรุปผลการเรียนรู้

เก่งมาก! คุณทำภารกิจและเข้าใจ Loop ใน Python แล้ว

LOOP (การวนซ้ำ)

คือการสั่งให้โปรแกรมทำงานเดิมซ้ำๆ เพื่อลดการเขียนโค้ดซ้ำซ้อน

WHILE Loop

ทำงานวนซ้ำ "ขณะที่" เงื่อนไขยังคงเป็นจริง (True)

FOR Loop

ทำงานวนซ้ำตามจำนวนรอบที่แน่นอน หรือวนตามสมาชิกในกลุ่ม

RANGE Function

คำสั่งสร้างชุดตัวเลข เช่น range(1,4) ได้ 1, 2, 3

NESTED Loop

ลูปซ้อนลูป (Loop ใน Loop) ใช้จัดการข้อมูล 2 มิติ เช่น ตาราง หรือ พิกัด X, Y

CONTINUE Statement

สั่งให้โปรแกรม "ข้าม" การทำงานในรอบปัจจุบัน และไปเริ่มรอบถัดไปทันที
